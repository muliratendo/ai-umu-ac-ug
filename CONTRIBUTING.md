# Contributing

Work from the repository root for Git commands and `apps/platform` for application
commands. Install locked dependencies, run the focused test suite and frontend build,
and run `git diff --check` before submitting changes. Do not commit secrets or
modify vendor files.

Record material technical and non-technical decisions in
[`docs/decisions/REGISTER.md`](docs/decisions/REGISTER.md), including decisions
discovered during implementation. Link detailed narratives to ADRs under
`docs/architecture/decisions/` or topic docs.
